# Homepage quote form

Import this on the site. It is not created by the theme.

1. Fluent Forms → Tools → Import, and upload `homepage-quote.json`.
2. Open **Homepage – Quote Request** and set **Form Style** to **None**.
3. Copy its ID into the front page field **Fluent Form ID** (`cta_form`).
4. The notification goes to `info@kogler-usa.com`. Change that address if the live homepage form uses a different inbox.
5. Leave the site honeypot on. Do not add a new captcha.
6. There is no SMS checkbox. Add the Contact page disclosure only if this phone number is used for texts.
